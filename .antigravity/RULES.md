# Governance Rules

All development in this repository must adhere to the high-level standards defined in `.antigravity-rules.md`.

## Core Disciplines

1. **Commit Discipline**: One logical change per commit using Conventional Commits.
2. **Branching Strategy**: Use flow-based branching (`feature/`, `fix/`, `chore/` off `develop`).
3. **Pull Request Standards**: Every PR must follow the template and undergo review.
4. **Documentation Rules**: Keep README and docs updated; use proper docstrings.
5. **Testing Expectations**: Every feature and fix must include tests.
6. **Refactor Rules**: Refactors must not change behavior and must be separate from features.
